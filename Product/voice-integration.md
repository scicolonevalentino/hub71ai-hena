# Hena voice integration — MVP contract (2 October 2026)

**Status.** Valentino created a new ElevenLabs key for Hena. It is stored only in `MVP/.env.local` with file mode `600` and excluded by the root `.gitignore`. Read-only account and agent API checks returned `200`. One private agent, “Hena Abu Dhabi”, was created and its ID was saved in the same local environment file. The agent is set to English, uses the native OpenAI `gpt-4.1-mini` model and an English voice, and has four knowledge documents generated from the verified JSON cards in `Sources/`. Three live written questions returned in 2–3 seconds after this model change, and one live voice reply began audio in 1.3 seconds. Earlier slow voice turns used ElevenLabs' default Gemini backup and took roughly 6 seconds for the LLM's first sentence. Its signed URL endpoint responded successfully. Audio saving is disabled and conversation retention is set to one day. In the local browser, the live session reached Listening, transcribed a short utterance, displayed an English agent reply, entered the speaking state, and stopped through the visible button. VoiceOver behavior has not yet been tested.

**Recommendation.** Use one ElevenAgents agent with a natively integrated OpenAI model, one English voice, and four knowledge documents generated from the canonical JSON (documents, housing, transport, and 22 first-month experiences), with source URLs and verification dates. This route does not require a separate OpenAI API key for the integrated model. Agent prompt: answer in English, give a brief choice for a broad leisure question or one sourced next action for a specific interest, and say clearly when the documents do not support an answer. English applies to all app labels, typed messages, transcripts, first message, spoken output, and errors. Choose an English voice and test pronunciation of Abu Dhabi place names.

**Web contract.** Keep the main journey and answers readable as normal page text. The written form calls Hena's server for a grounded text answer; it remains usable without microphone access. Its text-only conversation ignores the voice welcome and waits for the answer to the submitted question. The prominent “Talk to Hena” button explicitly requests the microphone and starts the ElevenAgents session in one gesture. Its label changes to “Stop voice conversation” while active; closing the panel also stops it. A short English first message greets the person after connection. While Hena speaks, the SDK mutes the session microphone and unmutes it when listening resumes, so ambient noise cannot interrupt the answer; the visible Stop control still works. The transcript renders user and agent messages as ordinary text, without a second live announcement of the whole answer. A spoken transcript populates the written question field; a subsequent agent reply selects the matching source card when it names a source in the dataset, or opens the 22-idea chooser for a broad leisure reply. The official URL stays in the card and is not spoken by the agent. Voice never marks progress. The private agent's API key and ID stay on the server, which issues only a short-lived signed session URL to the browser. VoiceOver alongside app speech still needs a human test.

**Limits and today’s work.** The signed URL, one spoken exchange, supported written answers, one out-of-scope written answer, and the browser's start/stop controls have been tested. Exact audio quality, pronunciation, quota, latency under load, and VoiceOver overlap remain unverified. The four knowledge documents preserve each card's action, source URL, verification date, and limits. Do not claim formal accessibility conformance from this MVP test.
